Mit dem Syntax-Studio erstellen Sie aus einem lateinischen Text eine interaktive Übungsseite. Die Studierenden bestimmen darauf die Funktion jedes Wortes und jeder Wortgruppe im Satz, markieren Genitivattribute und übersetzen anschliessend. Die Seite gibt ihnen dabei sofort Rückmeldung.

Dieses Handbuch ergänzt die kurze Anleitung auf der Seite des Tools und erklärt alle Funktionen, die Ihnen zur Verfügung stehen. Für die Studierenden gibt es eine eigene Anleitung; wie das Ergebnis aussieht, zeigt die Beispielseite.

Latin Syntax Studio turns a Latin text into an interactive exercise page. On that page, students identify the function of every word and word group in the sentence, mark genitive attributes and then translate. The page gives them immediate feedback.

This handbook supplements the short instructions on the tool's own page and explains every function available to you. Students have a guide of their own; the example page shows what the result looks like.

1. Überblick: in vier Schritten zur Übung

  1. Text eingeben. Titel, lateinischer Text (bis 300 Wörter), auf Wunsch Hinweise und ein Bild; dazu die Grammatik-Stufe.
  2. Analysieren lassen oder selbst beginnen. Die KI schlägt eine vollständige Analyse vor. Sie können aber auch ohne KI beginnen oder ein gespeichertes Projekt laden.
  3. Im Editor prüfen und ergänzen. Funktionen korrigieren, Wortgruppen (Klammern) setzen, Genitivattribute markieren, zusammengehörige Wörter verbinden; auf Wunsch Hinweise, Erklärungen, Überschriften, Musterübersetzungen und Wortangaben hinzufügen.
  4. Schülerseite exportieren. Sie erhalten eine einzelne HTML-Datei, die Sie auf einer Lernplattform, einer Website oder per E-Mail weitergeben. Speichern Sie zusätzlich das Projekt, damit Sie es später weiterbearbeiten können.
Die Materialien im Überblick
  • Das Tool (Editor): für Sie, zum Erstellen der Übungen.
  • Die exportierte Schülerseite: die eigentliche Übung für die Studierenden.
  • Die Anleitung: erklärt den Studierenden das Vorgehen und alle Funktionen, mit zwei Übungssätzen.
  • Deklinationen und Konjugationen: Tabellen zum Nachschlagen; die Schülerseite verlinkt sie.
  • Die Texte des geführten Modus: eine Übersicht über alle Hinweise und Erklärungen, die die Studierenden im geführten Modus sehen können.

1. Overview: an exercise in four steps

  1. Enter the text. A title, the Latin text (up to 300 words), notes and an image if you like, and the grammar level.
  2. Let the AI analyse it, or start yourself. The AI suggests a complete analysis. You can also start without AI or load a saved project.
  3. Check and complete it in the editor. Correct functions, set word groups (brackets), mark genitive attributes, connect words that belong together; add hints, explanations, headings, model translations and word information if you wish.
  4. Export the student page. You get a single HTML file that you share on a learning platform, a website or by email. Also save the project so that you can keep working on it later.
The materials at a glance
  • The tool (editor): for you, to create exercises.
  • The exported student page: the exercise itself.
  • The guide: explains the method and every function to students, with two practice sentences.
  • Declensions and conjugations: reference tables; the student page links to them.
  • The texts of guided mode: an overview of every hint and explanation students can see in guided mode.

Analyse mit KI

Der Text wird an ein Sprachmodell von OpenAI geschickt. Die Antwort enthält für jedes Wort eine Funktion, markierte Genitivattribute und Klammern für Nebensätze und Konstruktionen. Danach öffnet sich der Editor. In der aktuellen Version ist der Zugang zur KI bereits eingerichtet; Sie brauchen keinen eigenen Schlüssel. Zeigt Ihre Version neben dem Knopf ein 🔑 API-Schlüssel, hinterlegen Sie dort einmalig Ihren eigenen OpenAI-Schlüssel. Er wird nur in Ihrem Browser gespeichert; verwenden Sie einen Schlüssel mit Ausgabenlimit und entfernen Sie ihn auf gemeinsam genutzten Geräten nach Gebrauch.

Wichtig: Die KI macht einen Vorschlag, keine fertige Lösung

Prüfen Sie jede Analyse im Editor. Typische Stellen, an denen sich ein zweiter Blick lohnt: Genitivattribute und ihre Bezugswörter, getrennt stehende Wörter in der Dichtung (Hyperbaton), mehrdeutige Endungen (Dativ oder Ablativ, Nominativ oder Akkusativ), die Grenzen von Nebensätzen und die Frage, ob ein Satz ein eigenes Subjekt hat. Stimmt die Antwort der KI nicht Wort für Wort mit Ihrem Text überein, zeigt das Tool die fehlenden oder zusätzlichen Wörter an; Sie können dann trotzdem übernehmen oder es erneut versuchen.

Solange Sie arbeiten, speichert das Tool den letzten Stand automatisch in Ihrem Browser. Öffnen Sie das Tool innerhalb von 24 Stunden erneut, bietet es an, diesen Stand wiederherzustellen. Diese Sicherung ersetzt nicht das Speichern als Datei (Abschnitt 9).

How to start

  • ✨ Analyze with AI: the AI creates a complete suggestion (see below).
  • Start Manual Creation: the text is split into words; you assign the functions yourself.
  • Load Saved Project: opens a project file saved earlier (.json) and takes you straight to the editor.

Analysis with AI

The text is sent to a language model from OpenAI. The answer contains a function for every word, marked genitive attributes and brackets for clauses and constructions. The editor then opens. In the current version access to the AI is already set up; you do not need a key of your own. If your version shows a 🔑 API key button next to it, enter your own OpenAI key there once. It is stored only in your browser; use a key with a spending limit and remove it after use on shared computers.

Important: the AI makes a suggestion, not a finished solution

Check every analysis in the editor. Places that deserve a second look: genitive attributes and the words they belong to, separated words in poetry (hyperbaton), ambiguous endings (dative or ablative, nominative or accusative), the limits of subordinate clauses, and whether a sentence has a subject of its own. If the AI's answer does not match your text word for word, the tool lists the missing or extra words; you can import it anyway or try again.

While you work, the tool automatically keeps the latest state in your browser. If you open the tool again within 24 hours, it offers to restore that state. This backup does not replace saving a file (section 9).

4. Funktionen zuweisen

Klicken Sie auf eine Funktion (zum Beispiel Akkusativobjekt) und dann auf die Wörter, die diese Funktion erhalten sollen. Die Funktion bleibt ausgewählt, bis Sie eine andere wählen. Schneller geht es mit der Tastatur: Zeigen Sie mit der Maus auf ein Wort und drücken Sie den unterstrichenen Buchstaben der Funktion (S für Subjekt, P für Prädikat …). Zeigen Sie dabei auf den Namen einer Klammer, erhält die Klammer diese Funktion.

Wie aus Wörtern Blöcke werden

Benachbarte Wörter mit derselben Funktion verschmelzen auf der Schülerseite zu einem Block, den die Studierenden als Ganzes bestimmen. Ein Komma zwischen zwei Wörtern derselben Funktion gehört dann mit in den Block. Daraus ergeben sich die Regeln, nach denen Sie (und die KI) analysieren:

  • Adjektive, Pronomen und Genitivattribute erhalten die Funktion ihres Bezugswortes: Hi omnes ist zusammen das Subjekt.
  • Eine Präposition bildet mit ihrem Substantiv eine präpositionale Bestimmung: in partes tres.
  • Durch et, -que, atque verbundene Teile derselben Funktion erhalten dieselbe Funktion, die Konjunktion eingeschlossen: Matrona et Sequana.
  • Zusammengesetzte Verbformen sind zusammen das Prädikat: divisa est.
  • Sonstiges verschmilzt nie: Jedes Wort mit dieser Funktion bleibt ein eigener Block.

Sollen zwei benachbarte Wörter mit derselben Funktion trotzdem getrennte Blöcke sein, setzen Sie mit Manuell trennen eine Trennlinie. Gehören Wörter zusammen, stehen aber getrennt (Hyperbaton), erhalten beide dieselbe Funktion; mit Wörter verbinden zeigen Sie zusätzlich, welches Wort wozu gehört.

Labels und Farben

  • Eigene Funktion: Namen in das Feld „Neues Label“ schreiben und auf + klicken, zum Beispiel für eine Interjektion. Eigene Funktionen, die Sie in der Übung nicht verwenden, erscheinen nicht auf der Schülerseite.
  • Farbe ändern: Auf ▾ neben einer Funktion klicken (oder mit der rechten Maustaste auf die Funktion). Zur Wahl stehen Farben, die auch bei Farbenblindheit gut zu unterscheiden sind. Ist eine Farbe schon vergeben, steht dabei, welche Funktion sie hat; diese wird dann grau. Mit „↺ Standardfarbe“ kehrt eine einzelne Funktion zu ihrer Grundfarbe zurück.
  • 🎨 Standardfarben wiederherstellen setzt alle Farben zurück.
  • 👁 Farbenblind-sichere Farben (über dem Text) gibt allen Funktionen dieser Übung auf einmal Farben, die bei allen Formen von Farbenblindheit unterscheidbar bleiben. Es gibt nur zehn solche Farben; bei mehr Funktionen erhalten die häufigsten sie. Ein zweiter Klick stellt die vorherigen Farben wieder her.
  • Die Farben, die Sie wählen, sehen auch die Studierenden. Sie können sie auf ihrer Seite für sich ändern.

4. Assigning functions

Click a function (for example Accusative object) and then the words that should get it. The function stays selected until you choose another one. The keyboard is quicker: point at a word with the mouse and press the underlined letter of the function (S for Subject, P for Verb …). If you point at the name of a bracket instead, the bracket gets that function.

How words become blocks

On the student page, neighbouring words with the same function merge into one block, which students analyse as a whole. A comma between two words with the same function becomes part of the block. This leads to the rules by which you (and the AI) analyse:

  • Adjectives, pronouns and genitive attributes get the function of the word they belong to: Hi omnes together is the subject.
  • A preposition forms a prepositional phrase with its noun: in partes tres.
  • Parts joined by et, -que, atque that have the same function get that function, the conjunction included: Matrona et Sequana.
  • Compound verb forms are the verb together: divisa est.
  • Other never merges: every word with this function stays a block of its own.

If two neighbouring words with the same function should still be separate blocks, set a dividing line with Manual Split. If words belong together but stand apart (hyperbaton), both get the same function; with Connect Words you can also show which word belongs to which.

Labels and colours

  • A function of your own: type a name into “New Label” and click +, e.g. for an Interjection. Functions of your own that you do not use in the exercise do not appear on the student page.
  • Changing a colour: click ▾ next to a function (or right-click the function). You choose from colours that remain distinct for colour-blind viewers. If a colour is already in use, the picker says by which function; that function then turns grey. “↺ Default colour” returns a single function to its original colour.
  • 🎨 Default colours resets all colours.
  • 👁 Colour-blind-safe colours (above the text) gives all functions of this exercise colours that stay distinct for every form of colour blindness at once. There are only ten such colours; if there are more functions, the most frequent ones get them. A second click restores the previous colours.
  • Students see the colours you choose. They can change them for themselves on their page.

5. Werkzeuge

Jedes Werkzeug ist ein Modus: Ein Klick auf den Knopf schaltet ihn ein, ein zweiter Klick (oder Esc) zurück zum Markieren. Mit dem Tastaturkürzel wirkt ein Werkzeug direkt auf das Wort unter der Maus, ohne den Modus zu wechseln. Nach einem Werkzeug ist „Sonstiges“ als Funktion ausgewählt; wählen Sie zum Weitermarkieren wieder die gewünschte Funktion.

↶ Rückgängig (Strg+Z)

Macht den letzten Schritt rückgängig, auch mehrere Schritte nacheinander.

Manuell trennen (X)

Klicken Sie auf ein Wort: Rechts davon erscheint eine Trennlinie, und das Wort bleibt auf der Schülerseite ein eigener Block, auch wenn das nächste Wort dieselbe Funktion hat. Ein zweiter Klick entfernt die Linie. Hat die KI mehrere Wörter als eines geliefert (zum Beispiel a Clodia), teilt derselbe Klick sie in einzelne Wörter.

Umbruch umschalten (W)

Steuert, wo ein Satz endet. Ein Klick auf ein Wort oder Satzzeichen beginnt danach einen neuen Satz, etwa nach einem Doppelpunkt oder Semikolon, wenn ein langer Satz in zwei Übungssätze aufgeteilt werden soll. Ein Klick auf einen Punkt hebt das Satzende dort auf, etwa nach einer Abkürzung wie C. Jeder Satz erhält auf der Schülerseite ein eigenes Übersetzungsfeld, eine eigene Überschrift und Musterübersetzung, und der geführte Modus geht Satz für Satz vor.

Wortgruppe definieren (M)

Klammern fassen eine Einheit zusammen: Nebensätze, Relativsätze, AcI/NcI, Ablativus absolutus oder eine Wortgruppe mit Partizip. Klicken Sie auf das erste und dann auf das letzte Wort der Gruppe (oder zeigen Sie nacheinander auf beide und drücken Sie jeweils M); auf dem Tablet können Sie über die Wörter streichen. Dann wählen Sie den Namen der Gruppe.

  • Name: einer der Klammer-Namen oder jede andere Funktion. Eine Wortgruppe mit Partizip benennen Sie meist nach ihrer Aufgabe im Satz (zum Beispiel Subjekt) und geben dem Partizip selbst die Funktion Partizip; Sie können die Klammer aber auch „Partizip“ nennen.
  • Grenzen ändern: Mit den Pfeilen ◀ ▶ am Anfang und am Ende der Klammer verschieben Sie die Grenze um ein Wort; Sie können die Pfeile auch auf ein anderes Wort ziehen.
  • Bearbeiten: Ein Klick auf den Namen öffnet das Fenster wieder (Name, Hinweise, Erklärung). ✖ löscht die Klammer.
  • Verschachteln: Klammern dürfen ineinander liegen, etwa ein Relativsatz in einem Nebensatz.
  • Die Wörter in einer Klammer bestimmen die Studierenden nach ihrer Aufgabe innerhalb der Einheit. Die Klammer selbst müssen sie ebenfalls benennen; auf der Schülerseite steht dafür ein ? über der Klammer.

Genitiv markieren (G)

Ein Genitivattribut steht im Block seines Bezugswortes und hat dessen Funktion. Mit diesem Werkzeug unterstreichen Sie es; im Editor steht dann „(Gen)“ unter dem Wort. Die Studierenden müssen jedes markierte Genitivattribut selbst finden und markieren, bevor das Übersetzungsfeld erscheint; im Prüfungsmodus zählt jedes als eigener Punkt. Ein zweiter Klick hebt die Markierung auf. Ein Genitivobjekt (abhängig von einem Verb oder Adjektiv) ist dagegen eine eigene Funktion und wird nicht markiert.

Wörter verbinden (H)

Verbindet einzelne Wörter, die zusammengehören, aber getrennt stehen, zum Beispiel saevae … īram oder tuo … aequore. Klicken Sie zuerst das abhängige Wort an, dann das Wort, zu dem es gehört. Mehrere Wörter können auf dasselbe Wort zeigen; ein verbundenes Wort zweimal anklicken löst die Verbindung. Verbinden lassen sich nur Wörter desselben Satzes. Die Studierenden sehen einen gestrichelten Bogen von Wort zu Wort; die Blöcke bleiben, wie sie sind. Der geführte Modus nutzt die Verbindungen für seine Hinweise.

Sobald es Verbindungen gibt, erscheint unter dem Text die Option „Verbindungen erst zeigen, wenn beide Blöcke bestimmt sind“. Damit verraten die Bögen nichts im Voraus. Im Prüfungsmodus erscheinen die Bögen immer erst dann.

Doppelklick auf ein Wort

Öffnet ein Fenster, in dem Sie das Wort selbst korrigieren (zum Beispiel einen Tippfehler oder Längenzeichen), Hinweise und eine Erklärung hinzufügen (Abschnitt 6) oder das Wort mit Löschen entfernen.

5. Tools

Each tool is a mode: one click on the button turns it on, a second click (or Esc) returns to tagging. The keyboard shortcut applies a tool directly to the word under the mouse without changing the mode. After using a tool, “Other” is the selected function; choose the function you want before tagging again.

↶ Undo (Ctrl+Z)

Undoes the last step; you can undo several steps in a row.

Manual Split (X)

Click a word: a dividing line appears to its right, and the word stays a block of its own on the student page even if the next word has the same function. A second click removes the line. If the AI returned several words as one (e.g. a Clodia), the same click splits them into single words.

Toggle Break (W)

Controls where a sentence ends. A click on a word or punctuation mark starts a new sentence after it, for example after a colon or semicolon when a long sentence is to become two exercise sentences. A click on a full stop removes the sentence end there, for example after an abbreviation such as C. On the student page every sentence gets its own translation box, heading and model translation, and guided mode works sentence by sentence.

Define Word Group (M)

Brackets mark a unit: subordinate and relative clauses, accusative/nominative with infinitive, ablative absolute, or a phrase with a participle. Click the first and then the last word of the group (or point at each in turn and press M); on a tablet you can swipe across the words. Then choose the name of the group.

  • Name: one of the bracket names or any other function. A phrase with a participle is usually named after its job in the sentence (e.g. Subject), and the participle itself gets the function Participle; you can also call the bracket “Participle”.
  • Changing the limits: the arrows ◀ ▶ at the start and end of the bracket move its limit by one word; you can also drag the arrows onto another word.
  • Editing: a click on the name opens the dialog again (name, hints, explanation). ✖ deletes the bracket.
  • Nesting: brackets may lie inside each other, e.g. a relative clause inside a subordinate clause.
  • Students analyse the words in a bracket according to their job within the unit. They also have to name the bracket itself; on the student page there is a ? above it for this.

Mark Genitive (G)

A genitive attribute stands in the block of the word it belongs to and has that word's function. This tool underlines it; in the editor “(Gen)” then appears under the word. Students have to find and mark every marked genitive attribute themselves before the translation box appears; in exam mode each one counts as a point of its own. A second click removes the mark. A genitive object (depending on a verb or adjective), by contrast, is a function of its own and is not marked.

Connect Words (H)

Connects single words that belong together but stand apart, for example saevae … īram or tuo … aequore. First click the dependent word, then the word it belongs to. Several words can point to the same word; clicking a connected word twice removes the connection. Only words in the same sentence can be connected. Students see a dashed arc from word to word; the blocks stay as they are. Guided mode uses the connections for its hints.

As soon as there are connections, the option “Show connections only once both blocks are solved” appears below the text, so that the arcs give nothing away in advance. In exam mode the arcs always appear only then.

Double-clicking a word

Opens a dialog in which you correct the word itself (a typo, say, or vowel lengths), add hints and an explanation (section 6) or remove the word with Delete.

6. Hinweise und Erklärungen

Für jedes Wort (Doppelklick) und jede Klammer (Klick auf den Namen) können Sie drei Texte hinterlegen. Alle sind freiwillig; ohne sie greift der geführte Modus auf seine allgemeinen Hinweise zurück. Lateinische Wörter setzen Sie zwischen Sternchen, damit sie kursiv erscheinen: *omnis* wird zu omnis.

FeldWo die Studierenden es sehen
HinweisAls 💡 am Block bzw. an der Klammer, in allen Modi. Die Studierenden öffnen ihn selbst, wenn sie Hilfe brauchen. Beispiel: „Welche Funktion hat omnis in diesem Satz?“ oder „ergänze: est“.
Hinweis nach falscher AntwortNach einer falschen Antwort: im Übungsmodus in der Rückmeldung, im geführten Modus anstelle des automatischen Tipps.

Welche automatischen Hinweise und Erklärungen der geführte Modus sonst zeigt, finden Sie in der Übersicht der Texte des geführten Modus.

6. Hints and explanations

For every word (double-click) and every bracket (click its name) you can add three texts. All are optional; without them, guided mode uses its general hints. Put Latin words between asterisks to have them in italics: *omnis* becomes omnis.

FieldWhere students see it
HintAs 💡 on the block or bracket, in all modes. Students open it themselves when they need help. Example: “What function does omnis have in this sentence?” or “supply: est”.
Hint after wrong answerAfter a wrong answer: in practice mode in the feedback, in guided mode instead of the automatic tip.
Explanation after a correct answerIn guided mode after the correct answer, instead of the general explanation of the function.

The automatic hints and explanations guided mode shows otherwise are listed in the overview of the texts of guided mode.

7. Überschriften und Musterübersetzungen

Unter dem Text klappen Sie „📝 Überschriften und Musterübersetzungen“ auf. Für jeden Satz gibt es zwei Felder:

  • Überschrift (optional): steht über dem Satz, zum Beispiel die Textstelle. *Sternchen* setzen Text kursiv: Caesar, *De bello Gallico* 1,1. Eine Überschrift gliedert auch Texte aus mehreren Autoren, wie auf der Beispielseite.
  • Musterübersetzung (optional): Die Studierenden können sie öffnen, sobald sie selbst eine Übersetzung geschrieben haben, und beide vergleichen. Bis dahin ist der Knopf ausgegraut, und ein kurzer Satz erklärt, warum. Im Prüfungsmodus bleibt die Musterübersetzung verborgen, bis die Prüfung abgegeben ist.

Die Zahl neben der Überschrift zeigt, für wie viele Sätze schon eine Musterübersetzung eingetragen ist. Ändern Sie später die Satzgrenzen, prüfen Sie, ob Überschriften und Übersetzungen noch beim richtigen Satz stehen.

7. Headings and model translations

Below the text, open “📝 Headings and model translations”. Each sentence has two fields:

  • Heading (optional): stands above the sentence, e.g. the passage. *Asterisks* set text in italics: Caesar, *De bello Gallico* 1.1. Headings also structure texts by several authors, as on the example page.
  • Model translation (optional): students can open it once they have written a translation of their own, and compare the two. Until then the button is greyed out, and a short sentence explains why. In exam mode the model translation stays hidden until the exam has been submitted.

The number next to the heading shows for how many sentences a model translation has been entered. If you change sentence boundaries later, check that headings and translations still belong to the right sentence.

8. Wortangaben

Unter „📖 Wortangaben“ stehen zu jedem Wort die Grundform (wie im Wörterbuch), die Form im Text und die Bedeutung. Die Studierenden öffnen sie über das 📖 an einem Block.

  • ✨ Mit KI erstellen füllt die Tabelle. Die Bedeutung steht in der Grundform (bei Verben im Infinitiv). Bereits geprüfte Einträge bleiben erhalten, wenn Sie die KI erneut fragen.
  • Prüfen: Einträge der KI sind orange markiert, bis Sie sie geprüft haben. Ein geänderter Eintrag oder ein Häkchen bei „Geprüft“ gilt als geprüft; ✓ Alle als geprüft markieren erledigt das für alle auf einmal. Beim Export weist das Tool auf ungeprüfte Einträge hin.
  • Zeigen: Hier wählen Sie, welche Wörter die Studierenden sehen. Die KI schlägt vor, sehr häufige Wörter (et, in, est …) und Namen wegzulassen. Alle zeigen und Keine zeigen schalten alle auf einmal um.
  • Form auch den Studierenden zeigen: standardmässig aus, weil die Form oft die Funktion verrät (Akkusativ → Objekt). Schalten Sie sie ein, sehen die Studierenden zusätzlich Kasus, Person usw.
  • Sie können jedes Feld auch selbst ausfüllen, ganz ohne KI.

8. Word information

“📖 Word information” lists, for every word, its dictionary form, its form in the text and its meaning. Students open it via the 📖 on a block.

  • ✨ Create with AI fills in the table. The meaning is given for the dictionary form (for verbs, the infinitive). Entries you have already checked are kept when you ask the AI again.
  • Checking: entries from the AI are marked in orange until you have checked them. An edited entry or a tick under “Checked” counts as checked; ✓ Mark all as checked does this for all at once. When you export, the tool points out unchecked entries.
  • Show: here you choose which words students see. The AI suggests leaving out very common words (et, in, est …) and names. Show all and Show none switch all at once.
  • Also show the form to students: off by default, because the form often gives the function away (accusative → object). If you turn it on, students also see case, person and so on.
  • You can also fill in every field yourself, without any AI.

10. Die Schülerseite

Die Studierenden klicken auf einen Block (oder auf das ? über einer Klammer) und wählen die Funktion aus einem Menü. Genitivattribute markieren sie, indem sie direkt auf das Wort klicken und „🖍️ Genitiv markieren“ wählen. Ist ein Satz vollständig bestimmt, erscheint das Übersetzungsfeld. Oben wählen sie einen von drei Modi:

ModusSo funktioniert er
ÜbungsmodusDie Seite startet in diesem Modus. Die Studierenden bestimmen die Blöcke in beliebiger Reihenfolge. Nach einer falschen Antwort erhalten sie eine Rückmeldung (mit Ihrem „Hinweis nach falscher Antwort“, falls vorhanden); nach der zweiten falschen Antwort zeigt die Seite die Lösung.
Geführter ModusDie Seite führt Block für Block durch jeden Satz, von links nach rechts. Nach einer falschen Antwort gibt sie Hinweise in Stufen: zuerst eine Frage, dann einen Hinweis auf die entscheidende Form, dann zwei Funktionen zur Wahl und die Möglichkeit, sich die Lösung zeigen zu lassen. Nach jeder richtigen Antwort folgt eine kurze Erklärung. „Noch offen“ zeigt, was ein Leser an dieser Stelle noch erwartet (etwa ein Prädikat). Wer viele Antworten auf Anhieb richtig hat, erhält kürzere Hinweise; nach Fehlern werden sie wieder ausführlicher, und die Studierenden können selbst zwischen „Weniger Hilfe“ und „Mehr Hilfe“ wechseln. Am Ende jedes Satzes erscheint ein Übersetzungsplan, der die Teile des Satzes in eine Reihenfolge für die Übersetzung bringt. Die Studierenden können frühere Erklärungen nochmals ansehen und mit jedem Satz beginnen.
PrüfungsmodusJeder Block und jede Klammer hat genau einen Versuch: Richtiges wird bestätigt, Falsches rot umrandet und mit der richtigen Lösung versehen. Musterübersetzungen sind verborgen, Verbindungsbögen erscheinen erst nach dem Bestimmen. Mit „✅ Prüfung abgeben“ (oder sobald alles bestimmt ist) erhalten die Studierenden ihr Ergebnis: einen Punkt für jeden richtig bestimmten Block, jede Klammer und jedes gefundene Genitivattribut. Unbeantwortetes zählt als Fehler. Das Ergebnis (Übung, Datum, Punkte, Prozent) können sie kopieren und Ihnen schicken; die Übersetzungen werden nicht bewertet.

Wer den Modus wechselt, nachdem er schon etwas bestimmt hat, beginnt nach einer Rückfrage von vorn.

Weitere Funktionen der Schülerseite

  • Legende (Syntaktische Funktionen): alle Funktionen mit ihren Farben. Ein Klick ändert die Farbe für die Studierenden selbst; „↺“ kehrt zu Ihren Farben zurück. Darunter stehen die Tastenkürzel und die Links zu Anleitung, Deklinationen und Konjugationen.
  • 💡 Hinweise und 📖 Wortangaben an den Blöcken, Verbindungsbögen und Ihre Überschriften.
  • Ansicht: 🏁 Muster zusätzlich zu den Farben, 👁 farbenblind-sichere Farben, 🌗 hoher Kontrast, Aa Lesehilfe (grössere, leichter lesbare Schrift; gilt auch für die Anleitung und die Tabellen), Zoom.
  • EN/DE: Sprache der Oberfläche und der Funktionsnamen.
  • 💾 Fortschritt speichern / 🗑️ Fortschritt löschen: Der Stand wird nur in diesem Browser auf diesem Gerät gespeichert.
  • Drucken: druckt die Analyse mit den Übersetzungen, ohne Hinweise und Bedienelemente; zu jedem Satz gibt es Linien für eine handschriftliche Übersetzung.
  • HTML herunterladen: speichert eine Kopie der Seite.

10. The student page

Students click a block (or the ? above a bracket) and choose the function from a menu. They mark genitive attributes by clicking the word itself and choosing “🖍️ Mark Genitive”. Once a sentence is fully analysed, the translation box appears. At the top they choose one of three modes:

ModeHow it works
Practice modeThe page opens in this mode. Students analyse the blocks in any order. After a wrong answer they get feedback (with your “hint after wrong answer”, if there is one); after the second wrong answer the page shows the solution.
Guided modeThe page leads students block by block through each sentence, from left to right. After a wrong answer it gives hints in steps: first a question, then a pointer to the decisive form, then two functions to choose from and the option to see the solution. Every correct answer is followed by a short explanation. “Still open” shows what a reader still expects at this point (a verb, for instance). Students who get many answers right at the first attempt get shorter hints; after mistakes they become fuller again, and students can switch between “Less help” and “More help” themselves. At the end of each sentence a translation plan puts the parts of the sentence in an order for translating. Students can look back at earlier explanations and start with any sentence.
Exam modeEvery block and bracket has exactly one attempt: correct answers are confirmed, wrong ones outlined in red and given the correct solution. Model translations are hidden, and connecting arcs appear only once the blocks are solved. With “✅ Submit exam” (or as soon as everything is answered) students get their result: one point for each correct block, each bracket and each genitive attribute found. Anything unanswered counts as wrong. They can copy the result (exercise, date, points, percentage) and send it to you; translations are not marked.

Students who switch modes after they have already answered something start again from the beginning, after confirming.

Further functions of the student page

  • Legend (syntactic functions): every function with its colour. A click changes the colour for the student; “↺” returns to your colours. Below it are the keyboard shortcuts and the links to the guide, declensions and conjugations.
  • 💡 hints and 📖 word information on the blocks, connecting arcs and your headings.
  • View: 🏁 patterns in addition to the colours, 👁 colour-blind-safe colours, 🌗 high contrast, Aa reading aid (larger, easier-to-read text; it also applies to the guide and the tables), zoom.
  • EN/DE: language of the interface and the function names.
  • 💾 Save progress / 🗑️ Clear progress: the state is stored only in this browser on this device.
  • Print: prints the analysis with the translations, without hints and controls; each sentence gets lines for a handwritten translation.
  • Download HTML: saves a copy of the page.

12. Tipps und häufige Fragen

Welche Stufe passt?
„Anfänger“ für die ersten Lektionen mit Satzgliedern; „Fortgeschritten“, sobald Nebensätze, Infinitive und Prädikativa vorkommen; „Profi“ für Originaltexte mit AcI, Ablativus absolutus und Partizipien. Kommt in einem Text etwas über der Stufe vor, können Sie die Funktion trotzdem verwenden; sie erscheint dann auch im Menü der Studierenden.
Wie lang sollte ein Text sein?
Höchstens 300 Wörter; für eine Sitzung genügen meist drei bis acht Sätze. Sehr lange Perioden lassen sich mit „Umbruch umschalten“ in mehrere Übungssätze teilen.
Die KI hat ein Genitivattribut übersehen oder falsch zugeordnet.
Weisen Sie dem Wort die Funktion seines Bezugswortes zu und markieren Sie es mit „Genitiv markieren“. Steht es getrennt vom Bezugswort, verbinden Sie die beiden zusätzlich.
Zwei gleiche Funktionen stehen nebeneinander, sind aber verschiedene Satzglieder.
Setzen Sie mit „Manuell trennen“ eine Trennlinie nach dem ersten.
Ich möchte eine Übung für eine andere Gruppe abwandeln.
Laden Sie die Projektdatei, ändern Sie Stufe, Hinweise oder Musterübersetzungen und exportieren Sie unter einem anderen Titel.
Wo werden Daten gespeichert?
Ihr Projekt speichern Sie selbst als Datei; das Tool hält zusätzlich eine Sicherung in Ihrem Browser. Für die KI-Analyse und die Wortangaben wird der lateinische Text an OpenAI geschickt. Die Schülerseite sendet keine Daten: Fortschritt und Farben der Studierenden bleiben in ihrem eigenen Browser, und Prüfungsergebnisse erhalten Sie nur, wenn die Studierenden sie Ihnen schicken.
Ich habe nach dem Export etwas korrigiert.
Exportieren Sie die Seite erneut und ersetzen Sie die alte Datei. Gespeicherter Fortschritt der Studierenden passt nur dann noch, wenn Titel und Text gleich geblieben sind; nach grösseren Änderungen beginnen sie am besten neu.

12. Tips and frequent questions

Which level is right?
“Beginner” for the first lessons on sentence functions; “Intermediate” once subordinate clauses, infinitives and predicatives occur; “Advanced” for original texts with accusative with infinitive, ablative absolute and participles. If a text contains something above its level, you can still use the function; it then also appears in the students' menu.
How long should a text be?
At most 300 words; three to eight sentences are usually enough for one session. Very long periods can be divided into several exercise sentences with “Toggle Break”.
The AI missed a genitive attribute or attached it to the wrong word.
Give the word the function of the word it belongs to and mark it with “Mark Genitive”. If it stands apart from that word, also connect the two.
Two identical functions stand next to each other but are different parts of the sentence.
Set a dividing line after the first one with “Manual Split”.
I want to adapt an exercise for another group.
Load the project file, change the level, hints or model translations, and export under a different title.
Where is data stored?
You save your project yourself as a file; the tool also keeps a backup in your browser. For the AI analysis and the word information, the Latin text is sent to OpenAI. The student page sends no data: students' progress and colours stay in their own browser, and you receive exam results only if students send them to you.
I corrected something after exporting.
Export the page again and replace the old file. Students' saved progress only still fits if the title and the text are unchanged; after larger changes they had better start afresh.
